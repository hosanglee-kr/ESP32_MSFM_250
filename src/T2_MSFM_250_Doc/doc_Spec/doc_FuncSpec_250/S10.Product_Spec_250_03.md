# MSFM_T2_250 통합 제품 소개서 및 기술 규격서

## 제1부. 제품 소개서 (설비 관리자 중심 가치 및 활용 명세)
### 1. 개요 및 도입 가치
 * 회전 및 진동 설비의 초기 고장 징후를 현장에서 실시간 포착하는 엣지 분석 센서임
 * 단순 데이터 수집을 넘어 센서 내부에서 고성능 신호처리와 특징량 추출을 동시 완료함
 * 가혹한 공정 환경에서 데이터 유실과 장비 벽돌화를 방지하는 다중 페일세이프 구조임
### 2. 현장 실무자 관점의 5대 핵심 기능 및 특장점
 * **현장 맞춤형 하이브리드 진단 엔진**
   * 소음과 진동 데이터를 인간의 감각처럼 상호 보완적으로 융합 분석함
   * 현장 상황에 맞춰 소음 또는 진동 도메인의 활성화 여부를 개별 선택 가능함
 * **공정 노이즈 격리를 위한 개별 필터 튜닝**
   * 메디안, DC 제거, FIR, IIR, 노치 필터의 적용 여부를 개별 온오프 제어함
   * 차단 주파수, 윈도우 함수, Q-Factor 등 세부 옵션을 웹 화면에서 즉시 변경함
 * **룰(Rule) 기반 즉각 운영 및 미래 지향적 AI 자산 축적**
   * 도입 즉시 직관적인 다차원 룰 기반(RMS, 첨도, 밴드 에너지) 임계치로 감시를 시작함
   * 현재 TinyML 엔진은 추론용 16바이트 정렬 텐서 플랫 버퍼 할당 구조 등 인프라는 완비되어 향후 고도화 예정이며, 현재는 룰 기반으로 동작함
   * 방대한 Raw 파형 대신 압축된 특징량 데이터만 선별 축적하여 스토리지 효율을 극대화함
   * 정제된 데이터 축적을 통해 추후 딥러닝 모델 도입 시 데이터 라벨링 및 개발 기간을 단축함
 * **초고속 물리 안전 차단 인터록 (Interlock)**
   * OS 스케줄러 지연을 우회하여 레지스터 레벨에서 비상 차단 신호를 즉각 출력함
   * 설비 파손 임계치 도달 시 물리 릴레이를 제어하여 대형 자산 파손을 원천 차단함
 * **사고 전후 상황 복원 (타임머신 레코딩)**
   * PSRAM을 통해 평상시 대기 상태에서도 최근 3초 분량의 데이터를 상시 버퍼링함
   * 고장 트리거 감지 시 "사고 직전 3초 + 사고 순간 + 사고 이후"를 블랙박스 형태로 저장함
   * 스택 오버플로우 방지 및 락 경합 방지를 위해 PSRAM 스냅샷 바운스 버퍼를 활용해 락 영역 밖에서 비차단 방식으로 안전 기입함
### 3. 센서별 추출 특징량 기반 고장 탐지 맵핑
 * **진동(Vibration) 도메인 활용 고장 진단**
   * 실효치(RMS): 전체 진동 에너지 총량 감시로 정렬 불량(Misalignment), 언밸런스 탐지함
   * 첨도(Kurtosis) 및 크레스트 팩터: 초기 충격성 신호 포착으로 베어링 내/외륜 초기 크랙 탐지함
   * 피크 주파수(Peak Frequency): 최대 진폭 주파수 추적으로 기어 마모 및 축 회전 이상 거동 감지함
   * 8분할 밴드 에너지: 특정 고장 주파수 대역을 타겟팅하여 설비 고유의 기계적 결함을 조기 선별함
 * **소음(Acoustic) 도메인 활용 고장 진단**
   * 스펙트럴 센트로이드: 소리의 날카로움 및 음색 변화를 추적하여 고속 마찰 및 윤활 부족 감지함
   * 옥타브 밴드 상대 에너지(Timbre): 이물질 유입에 따른 고주파 파열음 및 흡배기 밸브 누설 탐지함
### 4. 대표적 적용 시나리오
 * **시나리오 A: 전원 노이즈 환경의 미세 베어링 결함 감시**
   * 공장 내 60Hz 주전원 Hum 노이즈 대역에 노치 필터를 적용하여 핀포인트로 제거함
   * 저주파 흔들림은 FIR 필터로 깎아내고 베어링 결함 주파수 대역만 밴드 에너지를 걸어 감시함
 * **시나리오 B: 간헐 구동 설비의 초절전 예지보전 (배터리 모드)**
   * 평상시 딥슬립 상태를 유지하다가 설비 가동 충격 발생 시 하드웨어 인터럽트로 자동 깨어남
   * 프리트리거 버퍼를 활용해 가동 직전 상황부터 기록하고 가동 종료 후 다시 취침함
   * 딥슬립 진입 전 BMI270 Any-Motion 인터럽트 매핑 및 PMU 설정을 제어하고, 웨이크업 시 원래의 FIFO 워터마크 인터럽트로 원상복구함
 * **시나리오 C: 미래 AI 고도화를 위한 데이터 가동 인프라 구축**
   * 룰 기반으로 정상/이상 알람을 운영하며 39차원 MFCC 특징 벡터를 백그라운드에서 상시 추출함
   * 원시 데이터 대비 스토리지 용량을 절감하면서 향후 AI 모델 학습용 텐서 셋을 자동 적재함

## 제2부. 시스템 아키텍처 및 데이터 흐름
### 1. 4-Tier 도메인 격리 모델
 * **Tier 1. Hardware Interface & Capture**
   * 하드웨어 소스를 배타 제어하고 센서 원시 데이터를 초고속 인출하는 도메인임
   * CPU L1 캐시 일관성 제어(esp_cache_msync)를 통해 PSRAM DMA 버퍼의 데이터 오염을 예방함
   * 모든 센서 SPI 접근은 직접 API 호출 대신 ST_SpiTransaction_t 우선순위 큐 스케줄러를 경유하도록 함
 * **Tier 2. Signal Processing**
   * SIMD 가속 기반 고정밀 디지털 필터 체인 및 전처리를 담당하는 DSP 도메인임
   * 고정 필터 계수는 플래시 ROM 상주(SMEA_FLASH_RODATA)로 SRAM을 절약하고, 동적 노치 필터 계수는 런타임 업데이트를 위해 RAM 영역에 배치함
 * **Tier 3. Feature Extraction & Storage**
   * 룰 기반 판정, 스펙트럼 생성, 특징량 추출 및 비동기 저장을 수행하는 도메인임
   * 락 프리 링버퍼 포인터 교환을 활용하여 복사를 배제한 제로 카피 원칙을 준수함
 * **Tier 4. AI & MLOps (향후 확장 영역)**
   * 추론 텐서 조립 및 프리엠프티브 인터록 생명주기를 관장하는 최상위 제어 도메인임
### 2. 엔드투엔드 통합 데이터 파이프라인
 * **수집 단계**: Core 0에서 I2S DMA 인터럽트와 SPI FIFO 이벤트를 통해 데이터를 수집함
 * **중계 단계**: SPSC 락프리 순환 링버퍼(원자적 배리어 펜스 적용)를 매개로 코어 간 데이터 유실 없이 고속 중계함
 * **필터 단계**: 메디안 필터, DC 제거, FIR/IIR 필터 체인을 순차 통과시켜 원시 파형을 정제함
 * **추출 단계**: 2*N 복소수 FFT 변환, 통계 특징량 연산 및 Mel-Filterbank 기반 MFCC 추출을 완료함
 * **동기화 단계**: Software PLL 기반 Drop & Shift(25틱 뮤팅 가드) 시간축 정렬을 통해 APLL-SPI 클럭 편차를 보정함
 * **융합 단계**: 오디오 특징과 진동 특징을 조립하여 312차원 평탄화 텐서를 구성함
 * **출력 단계**: 판정 결과에 따라 SD 카드 비동기 기입 및 웹소켓 스트리밍 송출을 분기 처리함
### 3. 멀티태스킹 코어 바인딩 및 뮤텍스 운용
 * **ImuAcqTask 태스크 (Core 0 / 우선순위 12)**
   * BMI270 FIFO 워터마크 인터럽트에 동기화되어 SPI 버스에서 원시 데이터를 최우선 인출함
 * **AudProcTask 태스크 (Core 1 / 우선순위 6)**
   * I2S DMA 수신 이벤트로 깨어나 오디오 필터링, 특징 추출, 융합 판정을 24.3ms 주기로 수행함
 * **VibProcTask 태스크 (Core 1 / 우선순위 5)**
   * 1024 샘플 누적 주기(약 640ms)마다 진동 신호 필터링 및 다차원 특징량 연산을 처리함
   * 락 프리 링버퍼 포인터 교환을 통해 Zero-Copy 구조로 중계함
 * **StorageTask 태스크 (Core 0 / 우선순위 2)**
   * 실시간성 보장을 위해 하위 우선순위로 배치되어 SD 카드 파일 쓰기 및 로테이션을 전담함
   * 물리 쓰기 및 flush 수행 시 락 영역 외부에서 독립된 태스크로 수행되도록 뮤텍스를 디커플링함
 * **SPI 버스 경합 차단 원칙**
   * 수집 태스크와 설정/교정 태스크 간 경합 방지를 위해 SPI 트랜잭션 스케줄러 큐를 경유함
 * **LittleFS 파일 시스템 상호 배제**
   * Lazy Write 데몬 및 소음 프로필 입출력이 동시에 접근 시 발생하는 VFS 충돌 방지를 위해 _fsLock 도입함

## 제3부. 기술 세부 규격서
### 1. 컴퓨팅 및 제어 인프라 스펙
 * 메인 프로세서: ESP32-S3 (Dual-Core 32-bit, 240MHz), SIMD 행렬 연산 가속 지원함
 * 메모리 구조: 512KB 내부 SRAM 및 8MB 확장 PSRAM 활용, 정적 메모리 풀 구조 채택함
 * 유한상태머신(FSM): INIT, READY, WARM_UP, MONITORING, RECORDING, CALIBRATING, MAINTENANCE, ERROR 단계 제어함
   * WARM_UP 단계를 30초 도입하여 부팅 직후 LTA 미초기화로 인한 오경보 트리거를 방어함
   * SD_MMC 물리 I/O 장애 감지 시 상태를 ERROR로 강제 전이하고 긴급 경보 발령함
   * OTA 진입 시 하드웨어 인터럽트/DMA를 차단하고 Safe Point에서 자발적으로 대기하는 Graceful Pause/Resume 구현함
 * 시각 피드백: FSM 상태와 동기화된 전용 RGB LED 인디케이터 제어 로직을 내장함
### 2. 센서 인터페이스 규격
 * 소음 센서: ICS43434 MEMS 마이크로폰, I2S 32-bit DMA 방식으로 42,000Hz 고정 수집함
   * DMA 디스크립터 개수를 FFT 크기에 따라 자동 분할(백로그 깊이 최소 6)하여 WiFi 공존 유실 차단함
 * 진동 센서: Bosch BMI270 6축 IMU, 고속 SPI 인터페이스를 통해 1,600Hz 고정 수집함
   * 자이로는 FIR을 배제하고 초경량 IIR 바이쿼드 필터 구조체로 메모리를 절약함
 * 물리 차단 인터페이스: GPIO 25번 핀 연동, 비상시 나노초 단위 레지스터 직접 제어로 LOW 클리어함
### 3. DSP 엔진 및 특징량 추출 세부 사양
 * 메디안 필터: 가변 윈도우(3-Tap 또는 5-Tap) 지원, 위상 왜곡 없는 임펄스 노이즈 제거용임
 * DC 오프셋 제거: IEEE-754 비트 마스킹 적용, 중력 가속도 성분 및 물리적 편향치 차단함
 * 고정밀 필터 체인: 선형 위상 FIR(63-Taps) 및 고속 IIR 필터의 가변 차단 주파수 설정을 지원함
 * 적응형 노치 필터: 60Hz 주전원 험 노이즈 타겟팅 및 가변 Q-Factor 기반 급준 차단 기능을 제공함
 * 노이즈 게이트: 배경 소음 학습(NOISE LEARN) 기반 스펙트럴 서브트랙션 알고리즘을 수행함
 * 고주파 증폭: 프리엠프시스 계수(0.97) 기반 미세 결함 신호의 주파수 에너지 증폭을 지원함
 * 주파수 변환: Hann, Hamming, Blackman 등 가변 윈도잉 함수 및 에너지 스케일링 복소수 FFT(2*N 정렬 강제)를 가속함
### 4. 페일세이프 스토리지 보호 기술
 * 비동기 저장 엔진(A-DSE): 파일 기입 지연 은닉용 PSRAM 링버퍼 및 SRAM 바운스 버퍼를 운용함
   * 뮤텍스 락 디커플링으로 SD 물리 파일 기입 지연 시간 동안 실시간 데이터 수집 지연을 방지함
   * 기존 WAL(Write-Ahead Logging) 구조를 전면 폐기하고 NVS 표준 규격으로 전면 대체하여 단순화함
 * 타임머신 플러시: 이벤트 트리거 발생 시 상시 버퍼링된 과거 Pre-Trigger 데이터를 SD 카드 파일 최상단에 기록함
   * 스택 오버플로우 방지를 위해 정적 할당된 PSRAM 스냅샷 바운스 버퍼를 경유하여 락 격리 전송함
 * 무제한 로테이션: MB 또는 분 단위 순환 저장 기능, 특징량(.bin)과 원시 파일(.wav/.acc)을 쌍으로 관리함
 * 핫플러그 패닉 방어: 녹화 중 SD 카드 무단 탈거 시 무한 재시도를 차단하고 세션을 강제 락(Lock) 처리함
 * 버스 병목 제어: RECORDING 상태 진입 시 외부의 대용량 파일 다운로드 API 접근을 자동 차단함
### 5. 비동기 네트워크 통신 및 보안
 * WiFi Auto-Fallback: 최대 3개의 라우터 프로파일을 순회하며 백그라운드 비블로킹 재연결을 시도함
 * 웹소켓 스트리밍: 초당 60프레임 바이너리 송출, 지연 클라이언트 강제 회수(cleanupClients)로 OOM 방지함
 * MQTT 프로토콜: MQTT 3.1.1 규격 준수, 주기적 텔레메트리 보고 및 원격 제어 명령 수신 프레임워크 탑재함
   * WDT 패닉 발생 시 RTC 메모리(`g_CrashDiag`, 매직넘버 검증 탑재)에 유지된 직전 진단 정보를 재부팅 후 MQTT로 긴급 송출함
   * WiFi 연결 직후 NTP 동기화 완료 전까지 MQTT secure 클라이언트 시작을 유보하여 TLS 데드락을 방방지함
   * `CMD_RESTART_NETWORK` 명령 수신 시 MQTT 클라이언트 핸들을 완전 파괴 후 재생성하여 커넥션 누수를 차단함
 * OTA 보안 락: 무선 펌웨어 업데이트 구동 시 다중 접속을 원천 차단하는 HTTP 423 Locked 프로토콜 구현함
   * OTA 전송 오류 시 FSM 상태 복구 및 센서 스트림을 복구하는 Graceful Resume 설계가 탑재됨

# MSFM_T2_250 통합 제품 소개서 및 기술 규격서
## 제1부. 제품 소개서 (설비 관리자 중심 가치 및 활용 명세)
### 1. 개요 및 도입 가치
 * 회전 및 진동 설비의 초기 고장 징후를 현장에서 실시간 포착하는 엣지 분석 센서임
 * 단순 데이터 수집을 넘어 센서 내부에서 고성능 신호처리와 특징량 추출을 동시 완료함
 * 가혹한 공정 환경에서 데이터 유실과 장비 벽돌화를 방지하는 다중 페일세이프 구조임
### 2. 현장 실무자 관점의 5대 핵심 기능 및 특장점
 * **현장 맞춤형 하이브리드 진단 엔진**
   * 소음과 진동 데이터를 인간의 감각처럼 상호 보완적으로 융합 분석함
   * 현장 상황에 맞춰 소음 또는 진동 도메인의 활성화 여부를 개별 선택 가능함
 * **공정 노이즈 격리를 위한 개별 필터 튜닝**
   * 메디안, DC 제거, FIR, IIR, 노치 필터의 적용 여부를 개별 온오프 제어함
   * 차단 주파수, 윈도우 함수, Q-Factor 등 세부 옵션을 웹 화면에서 즉시 변경함
 * **룰(Rule) 기반 즉각 운영 및 미래 지향적 AI 자산 축적**
   * 도입 즉시 직관적인 다차원 룰 기반(RMS, 첨도, 밴드 에너지) 임계치로 감시를 시작함
   * 현재 TinyML 엔진은 미지원하나 향후 고도화를 위해 인공지능용 특징량을 내부 자동 생성함
   * 방대한 Raw 파형 대신 압축된 특징량 데이터만 선별 축적하여 스토리지 효율을 극대화함
   * 정제된 데이터 축적을 통해 추후 딥러닝 모델 도입 시 데이터 라벨링 및 개발 기간을 단축함
 * **초고속 물리 안전 차단 인터록 (Interlock)**
   * OS 스케줄러 지연을 우회하여 레지스터 레벨에서 비상 차단 신호를 즉각 출력함
   * 설비 파손 임계치 도달 시 물리 릴레이를 제어하여 대형 자산 파손을 원천 차단함
 * **사고 전후 상황 복원 (타임머신 레코딩)**
   * PSRAM을 통해 평상시 대기 상태에서도 최근 3초 분량의 데이터를 상시 버퍼링함
   * 고장 트리거 감지 시 "사고 직전 3초 + 사고 순간 + 사고 이후"를 블랙박스 형태로 저장함
### 3. 센서별 추출 특징량 기반 고장 탐지 맵핑
 * **진동(Vibration) 도메인 활용 고장 진단**
   * 실효치(RMS): 전체 진동 에너지 총량 감시로 정렬 불량(Misalignment), 언밸런스 탐지함
   * 첨도(Kurtosis) 및 크레스트 팩터: 초기 충격성 신호 포착으로 베어링 내/외륜 초기 크랙 탐지함
   * 피크 주파수(Peak Frequency): 최대 진폭 주파수 추적으로 기어 마모 및 축 회전 이상 거동 감지함
   * 8분할 밴드 에너지: 특정 고장 주파수 대역을 타겟팅하여 설비 고유의 기계적 결함을 조기 선별함
 * **소음(Acoustic) 도메인 활용 고장 진단**
   * 스펙트럴 센트로이드: 소리의 날카로움과 음색 변화를 추적하여 고속 마찰 및 윤활 부족 감지함
   * 옥타브 밴드 상대 에너지(Timbre): 이물질 유입에 따른 고주파 파열음 및 흡배기 밸브 누설 탐지함
### 4. 대표적 산업 현장 적용 시나리오
 * **시나리오 A: 전원 노이즈 환경의 미세 베어링 결함 감시**
   * 공장 내 60Hz 주전원 Hum 노이즈 대역에 노치 필터를 적용하여 핀포인트로 제거함
   * 저주파 흔들림은 FIR 필터로 깎아내고 베어링 결함 주파수 대역만 밴드 에너지를 걸어 감시함
 * **시나리오 B: 간헐 구동 설비의 초절전 예지보전 (배터리 모드)**
   * 평상시 딥슬립 상태를 유지하다가 설비 가동 충격 발생 시 하드웨어 인터럽트로 자동 깨어남
   * 프리트리거 버퍼를 활용해 가동 직전 상황부터 기록하고 가동 종료 후 다시 취침함
 * **시나리오 C: 미래 AI 고도화를 위한 데이터 가동 인프라 구축**
   * 룰 기반으로 정상/이상 알람을 운영하며 39차원 MFCC 특징 벡터를 백그라운드에서 상시 추출함
   * 원시 데이터 대비 스토리지 용량을 절감하면서 향후 AI 모델 학습용 텐서 셋을 자동 적재함
## 제2부. 시스템 아키텍처 및 데이터 흐름
### 1. 4-Tier 도메인 격리 모델
 * **Tier 1. Hardware Interface & Capture**
   * 하드웨어 소스를 배타 제어하고 센서 원시 데이터를 초고속 인출하는 도메인임
 * **Tier 2. Signal Processing**
   * SIMD 가속 기반 고정밀 디지털 필터 체인 및 전처리를 담당하는 DSP 도메인임
 * **Tier 3. Feature Extraction & Storage**
   * 룰 기반 판정, 스펙트럼 생성, 특징량 추출 및 비동기 저장을 수행하는 도메인임
 * **Tier 4. AI & MLOps (향후 확장 영역)**
   * 추론 텐서 조립 및 프리엠프티브 인터록 생명주기를 관장하는 최상위 제어 도메인임
### 2. 엔드투엔드 통합 데이터 파이프라인
 * **수집 단계**: Core 0에서 I2S DMA 인터럽트와 SPI FIFO 이벤트를 통해 데이터를 수집함
 * **중계 단계**: SPSC 락프리 순환 링버퍼를 매개로 하여 코어 간 데이터 유실 없이 고속 중계함
 * **필터 단계**: 메디안 필터, DC 제거, FIR/IIR 필터 체인을 순차 통과시켜 원시 파형을 정제함
 * **추출 단계**: FFT 변환, 통계 특징량 연산 및 Mel-Filterbank 기반 MFCC 추출을 완료함
 * **동기화 단계**: 이종 주기(소음 42kHz / 진동 1.6kHz)의 시간축을 정렬하고 Late-Sync를 수행함
 * **융합 단계**: 오디오 특징과 진동 특징을 조립하여 312차원 평탄화 텐서를 구성함
 * **출력 단계**: 판정 결과에 따라 SD 카드 비동기 기입 및 웹소켓 스트리밍 송출을 분기 처리함
### 3. 멀티태스킹 코어 바인딩 및 뮤텍스 운용
 * **ImuAcqTask 태스크 (Core 0 / 우선순위 12)**
   * BMI270 FIFO 워터마크 인터럽트에 동기화되어 SPI 버스에서 원시 데이터를 최우선 인출함
 * **AudProcTask 태스크 (Core 1 / 우선순위 6)**
   * I2S DMA 수신 이벤트로 깨어나 오디오 필터링, 특징 추출, 융합 판정을 24.3ms 주기로 수행함
 * **VibProcTask 태스크 (Core 1 / 우선순위 5)**
   * 1024 샘플 누적 주기(약 640ms)마다 진동 신호 필터링 및 다차원 특징량 연산을 처리함
 * **StorageTask 태스크 (Core 0 / 우선순위 2)**
   * 실시간성 보장을 위해 하위 우선순위로 배치되어 SD 카드 파일 쓰기 및 로테이션을 전담함
 * **SPI 버스 경합 차단 원칙**
   * 수집 태스크와 설정/교정 태스크 간 경합 방지를 위해 내부 뮤텍스 세마포어를 통과함
   * 타임아웃 설정을 통해 특정 태스크의 버스 독점 및 우선순위 역전 현상을 방지함
## 제3부. 기술 세부 규격서
### 1. 컴퓨팅 및 제어 인프라 스펙
 * 메인 프로세서: ESP32-S3 (Dual-Core 32-bit, 240MHz), SIMD 행렬 연산 가속 지원함
 * 메모리 구조: 512KB 내부 SRAM 및 8MB 확장 PSRAM 활용, 정적 메모리 풀 구조 채택함
 * 유한상태머신(FSM): INIT, READY, MONITORING, RECORDING 등 8단계 상태를 원자적으로 제어함
 * 시각 피드백: FSM 상태와 동기화된 전용 RGB LED 인디케이터 제어 로직을 내장함
### 2. 센서 인터페이스 규격
 * 소음 센서: ICS43434 MEMS 마이크로폰, I2S 32-bit DMA 방식으로 42,000Hz 고정 수집함
 * 진동 센서: Bosch BMI270 6축 IMU, 고속 SPI 인터페이스를 통해 1,600Hz 고정 수집함
 * 물리 차단 인터페이스: GPIO 25번 핀 연동, 비상시 나노초 단위 레지스터 직접 제어로 LOW 클리어함
### 3. DSP 엔진 및 특징량 추출 세부 사양
 * 메디안 필터: 가변 윈도우(3-Tap 또는 5-Tap) 지원, 위상 왜곡 없는 임펄스 노이즈 제거용임
 * DC 오프셋 제거: IEEE-754 비트 마스킹 적용, 중력 가속도 성분 및 물리적 편향치 차단함
 * 고정밀 필터 체인: 선형 위상 FIR(63-Taps) 및 고속 IIR 필터의 가변 차단 주파수 설정을 지원함
 * 적응형 노치 필터: 60Hz 주전원 험 노이즈 타겟팅 및 가변 Q-Factor 기반 급준 차단 기능을 제공함
 * 노이즈 게이트: 배경 소음 학습(NOISE LEARN) 기반 스펙트럴 서브트랙션 알고리즘을 수행함
 * 고주파 증폭: 프리엠프시스 계수(0.97) 기반 미세 결함 신호의 주파수 에너지 증폭을 지원함
 * 주파수 변환: Hann, Hamming, Blackman 등 가변 윈도잉 함수 및 에너지 스케일링 FFT를 가속함
### 4. 페일세이프 스토리지 보호 기술
 * 비동기 저장 엔진(A-DSE): 파일 기입 지연 은닉용 PSRAM 링버퍼 및 SRAM 바운스 버퍼를 운용함
 * 타임머신 플러시: 이벤트 트리거 발생 시 상시 버퍼링된 과거 3초 데이터를 SD 카드에 선제 기록함
 * 무제한 로테이션: MB 또는 분 단위 순환 저장 기능, 특징량(.bin)과 원시 파일(.wav/.acc)을 쌍으로 관리함
 * 핫플러그 패닉 방어: 녹화 중 SD 카드 무단 탈거 시 무한 재시도를 차단하고 세션을 강제 락(Lock) 처리함
 * 버스 병목 제어: RECORDING 상태 진입 시 외부의 대용량 파일 다운로드 API 접근을 자동 차단함
### 5. 비동기 네트워크 통신 및 보안
 * WiFi Auto-Fallback: 최대 3개의 라우터 프로파일을 순회하며 백그라운드 비블로킹 재연결을 시도함
 * 웹소켓 스트리밍: 초당 60프레임 바이너리 송출, 지연 클라이언트 강제 회수(cleanupClients)로 OOM 방지함
 * MQTT 프로토콜: MQTT 3.1.1 규격 준수, 주기적 텔레메트리 보고 및 원격 제어 명령 수신 프레임워크 탑재함
 * OTA 보안 락: 무선 펌웨어 업데이트 구동 시 다중 접속을 원천 차단하는 HTTP 423 Locked 프로토콜 구현함

1. 하드웨어 인터페이스 사양서 (HIS)

포함 내용

1.1 시스템 개요

· 제품명: SMEA-T240 (v245)
· 주요 기능: 3축 가속도(BMI270) + 3축 자이로 + 스테레오 마이크(ICS43434) + SD카드 저장 + WiFi/MQTT + 사용자 버튼 + RGB LED
· 동작 전압: 3.3V DC (내부 레귤레이터 사용 시 5V~12V 입력 가능 – 실제 보드 설계에 따라 명시)

1.2 커넥터 목록 및 타입

커넥터 ID 기능 타입 (예: JST SH, Molex PicoBlade, 핀헤더) 핀 수 매칭 커넥터
J1 전원 입력 (5-12V) JST PH 2.0mm 2핀 2 SM02B-PASS
J2 BMI270 센서 (외장형) JST SH 1.0mm 4핀 4 SM04B-SRSS
J3 외부 트리거/버튼 JST PH 2.0mm 2핀 2 SM02B-PASS
J4 SD 카드 모듈 (SPI) JST SH 1.0mm 6핀 6 SM06B-SRSS
J5 I2S 마이크 (ICS43434) JST SH 1.0mm 5핀 5 SM05B-SRSS
J6 RGB LED (외부) JST PH 2.0mm 4핀 4 SM04B-PASS

참고: 실제 PCB 커넥터 모델과 핀 배열은 보드 설계에 따라 조정 필요.

1.3 전기적 특성

신호 그룹 전압 레벨 최대 전류 주파수/속도 비고
전원 입력 5~12V DC 1A - 내부 3.3V LDO
I/O (일반) 3.3V 10mA - ESP32-S3 tolerant
SPI (BMI270) 3.3V - 10MHz CS/SCK/MOSI/MISO
I2S (마이크) 3.3V - 3.072MHz BCLK 32비트 데이터
SD카드 SPI 3.3V - 4MHz (초기) CLK/CMD/D0

1.4 환경 요구사항

· 동작 온도: -20℃ ~ +70℃ (산업용)
· 보호 등급: IP40 이상 (실내), 케이블 인출부는 IP65 권장
· 케이블 길이 제한: SPI 30cm 이내, I2S 50cm 이내, 전원 2m 이내 (AWG24 이상)

2. 커넥터 핀맵 (Connector Pinout Table)

예시: J2 – BMI270 센서 (4핀 JST SH 1.0mm)

핀 번호 신호 이름 방향 (주관점: PCB) 설명 전압 레벨 비고
1 VDD_3V3 출력 센서 전원 3.3V 최대 50mA
2 GND - 접지 0V 
3 SPI_MOSI 출력 마스터 출력 → 센서 3.3V 
4 SPI_CLK 출력 10MHz 클럭 3.3V 
5 SPI_MISO 입력 센서 출력 → 마스터 3.3V 
6 INT1 입력 인터럽트 (Any-Motion) 3.3V 풀다운 필요

실제 핀 수: BMI270은 6핀(전원, 접지, MOSI, MISO, CLK, INT) → J2는 6핀 커넥터 사용.

예시: J5 – I2S 마이크 (ICS43434) 5핀

핀 번호 신호 이름 방향 설명 전압 비고
1 VDD_3V3 출력 마이크 전원 3.3V 10mA
2 GND - 접지 0V 
3 BCLK 출력 Bit Clock (I2S) 3.3V ESP32 핀41
4 WS 출력 Word Select (LRCLK) 3.3V 핀42
5 DATA_IN 입력 오디오 데이터 3.3V 핀43

예시: J4 – SD 카드 모듈 (SPI) 6핀

핀 번호 신호 방향 설명 비고
1 VDD_3V3 출력 SD카드 전원 3.3V, 200mA
2 GND - 접지 
3 SPI_CLK 출력 4~10MHz 핀39
4 SPI_MOSI 출력 CMD 핀38
5 SPI_MISO 입력 D0 핀40
6 CD 입력 카드 감지 (옵션) 

필수: 모든 SPI 신호선은 22~33옴 직렬 종단 저항 권장.

사용자 버튼 (J3, 2핀)

핀 신호 설명
1 GND 
2 BUTTON ESP32 핀0, 내부 풀다운, active high

3. 배선 다이어그램 (Interconnect Diagram)

텍스트 기반 개략도:

```
[전원 공급기] 5~12V ---> J1 (2핀) ---> [보드 LDO 3.3V] ---> 모든 모듈

[보드] (ESP32-S3)
    ----
    |   |-- J2 ---> BMI270 (6핀 케이블, 차폐 권장)
    |   |-- J3 ---> 외부 버튼
    |   |-- J4 ---> SD 카드 모듈 (SPI, 6핀)
    |   |-- J5 ---> ICS43434 스테레오 마이크 (5핀)
    |   |-- J6 ---> RGB LED (4핀, 애노드 공통)
    ----

[모듈 간 거리 제한]
- BMI270: 최대 30cm (SPI 10MHz)
- 마이크: 최대 50cm (I2S, 3MHz BCLK)
- SD카드: 최대 20cm (SPI 4MHz)
```

차폐 요구사항:

· I2S 및 SPI 라인은 개별 접지 차폐 케이블 또는 꼬임쌍 사용.
· 오디오 DATA 라인은 주변 고속 클럭과 간섭 방지.

4. 전원 분배도 (Power Distribution Diagram)

```
외부 입력 (5V~12V)
        │
        ▼
    [보호 회로] (역전압 + 과전류)
        │
        ▼
    3.3V LDO (최대 500mA)
        │
    ────┼─────────────────────────
    │   │        │        │
    ▼   ▼        ▼        ▼
   ESP  BMI     마이크   SD카드
   (200mA) (50mA) (10mA) (150mA)
```

총 예상 전류: 400mA (피크 시 600mA) → LDO 1A 권장.

노이즈 필터:

· 각 모듈 VCC 핀에 0.1uF + 10uF 커패시터 (가급적 센서 근처에 배치)
· SPI/I2S 신선에 22pF~47pF 풀다운 (옵션)

5. 신호 무결성 가이드라인 (Signal Integrity Guidelines)

5.1 일반 원칙

· 케이블 길이 단축: SPI ≤ 30cm, I2S ≤ 50cm, 전원 ≤ 2m
· 임피던스 매칭: 단일 종단 3.3V 신호는 50Ω ±10% 권장 (직렬 22Ω 저항)
· 크로스토크 방지: 인접 핀 사이에는 GND 핀 배치 (가능한 경우)

5.2 SPI 버스 (BMI270)

· 권장 와이어: 30AWG 차폐 연선, 차폐는 한쪽만 GND 연결 (보드 측)
· 클럭 라인은 다른 신호와 최소 5mm 이격
· 리시버 측에 10pF~33pF 풀다운 (노이즈 필터)

5.3 I2S 버스 (마이크)

· BCLK = 3.072MHz (48kHz * 64FS) → 기본적으로 문제 적음.
· 단, DATA 라인은 BCLK 에지와 정렬되므로 스큐 관리 필요: 케이블 길이 차이 < 10cm
· 차폐 케이블 강력 권장 (특히 모터/인버터 환경)

5.4 SD카드 SPI

· 초기 400kHz 모드 후 고속(4MHz) 전환.
· 긴 케이블 사용 시 CRC 에러 발생 가능 → 10cm 이내 권장.
· 필요 시 버퍼 드라이버(SN74LVC1G125) 추가.

5.5 인터럽트 라인 (INT1)

· 외부 노이즈에 민감 → 10k 풀다운 + 1nF 커패시터 필터.

6. 조립 및 검사 절차서 (간략)

하네스 제작 검사 항목

· 커넥터 극성 및 핀 위치 일치 (멀티미터로 단선/합선 테스트)
· 차폄 연결이 보드 GND에 단일 연결되었는가?
· 케이블 길이 규격 준수 (30cm, 50cm, 2m)
· 전원 라인에 부적절한 역전압 방지 다이오드 포함?
· 모든 나사/조임쇠 체결 토크 기준 (0.2~0.3Nm)

현장 설치 체크리스트

· BMI270 센서는 진동 측정 방향(화살표)에 맞게 장착
· 마이크 홀(ICS43434)이 외부 소음원 방향을 향하도록 배치
· SD카드 슬롯은 방진 커버로 보호
· 버튼 케이블은 움직임에 의한 단락 방지 (드레인 와이어 고정)
